Introducción

¿De qué trata este módulo?

En este módulo se aprende cómo poner en marcha una empresa bajo el modelo de asociatividad cooperativa utilizando herramientas tecnológicas reales. Se trabajan proyectos prácticos con Arduino, aplicaciones de escritorio y web, aplicaciones móviles y tiendas en línea.

Proyecto Agustine-Arduino

Arduino 01

Arduino es una plataforma de hardware y software que permite crear sistemas electrónicos de forma sencilla. En este módulo se utiliza para automatizar procesos dentro de una cooperativa.

  • Control de sensores (temperatura, humedad, movimiento)
  • Automatización de riego o iluminación
  • Sistemas de seguridad básicos
  • Monitoreo de inventarios o condiciones de almacenamiento
¿Qué se aprende? Los fundamentos de la electrónica y la programación de microcontroladores aplicados a un negocio real.
Sensores · Actuadores · Control
Proyecto WinForms y ASPX

Windows Forms + ASPX 02

Se desarrollan dos tipos de aplicaciones complementarias para la gestión de la cooperativa:

  • Windows Forms: aplicaciones de escritorio para gestionar socios, aportes, inventario y ventas.
  • ASPX: páginas web dinámicas para consultar y registrar información desde cualquier navegador.
¿Qué se aprende? Cómo crear sistemas de gestión (tipo administrativo) tanto para computadora como para la web.
Proyecto Final .NET MAUI

.NET MAUI 03

.NET MAUI permite crear aplicaciones que funcionan en Android, iOS y Windows con un solo código.

En el contexto de la cooperativa se usa para que los asociados puedan:

  • Consultar información desde el celular
  • Realizar pedidos o reportes
  • Recibir notificaciones
  • Acceder a datos importantes de forma móvil
¿Qué se aprende? Desarrollo de aplicaciones multiplataforma modernas.
Android iOS Windows
PrestaShop (Individual)

PrestaShop 04

PrestaShop es una plataforma profesional para crear tiendas en línea.

En este módulo se utiliza para que la cooperativa pueda vender sus productos por internet de forma ordenada y profesional (café, productos agrícolas, artesanías, etc.).

  • Catálogo de productos
  • Carrito de compras
  • Gestión de pedidos
  • Pasarelas de pago
¿Qué se aprende? Cómo crear y administrar una tienda virtual real.
Carrito de compras
Integración

¿Cómo se integran todas estas herramientas?

Arduino automatiza procesos físicos, WinForms y ASPX gestionan la información interna, .NET MAUI lleva la cooperativa al celular de los asociados, y PrestaShop permite vender los productos por internet. Juntas forman un ecosistema tecnológico completo.
