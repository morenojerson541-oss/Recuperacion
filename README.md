## Descripción

Esta página enseña de forma introductoria las tecnologías vistas en el Módulo 4:

- Arduino (Proyecto Agustine-Arduino)
- Windows Forms + ASPX
- .NET MAUI
- PrestaShop

Todo aplicado al contexto de la puesta en marcha de una empresa en asociatividad cooperativa.

## Características

- Contenido claro e introductorio
- Diseño corporativo responsive
- Quiz de 5 preguntas
- Ejercicio práctico con retroalimentación
- Tutor de IA que responde preguntas relacionadas con el contenido de la página
